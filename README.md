## 🎯 O que é uma Skill?

Uma **Skill** é um pacote autocontido de instruções técnicas, scripts, schemas e regras comportamentais especializadas (estruturado via SKILL.md). Elas transformam o assistente de IA em um especialista de domínio instantâneo, garantindo:
- **Zero Vibe Coding:** Execução orientada por rigor técnico, testes e padrões da indústria.
- **Diretrizes Karpathy:** Pensar antes de codificar, simplicidade radical, alterações cirúrgicas e verificabilidade.
- **Composabilidade:** Podem ser combinadas para orquestrar fluxos complexos (e.g. 	o-spec ➔ writing-plans ➔ subagent-driven-development ➔ code-review).
